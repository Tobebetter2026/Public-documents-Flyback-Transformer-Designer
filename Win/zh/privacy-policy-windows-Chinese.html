隐私政策（Windows 版）

最后更新：2026-06-07 · 适用于通过 Microsoft Store 分发的 Windows 版"反激式变压器设计工具"

本隐私政策（以下简称"政策"）适用于通过 Microsoft Store 分发的 Windows 版"反激式变压器设计工具"应用程序（以下简称"应用"、"我们"或"本方"）。本政策说明我们如何处理与您设备相关的信息。使用前请仔细阅读。

1. 简介

"反激式变压器设计工具"是一款本地计算的反激式变压器设计辅助工具，支持多路次级输出和 DCM / BCM / QR / CCM 等工作模式。应用界面提供简体中文和英文显示；语言偏好主要由您的设备系统语言设置决定，不改变本政策所述的数据处理原则。应用内置的磁芯和材料数据通过安装包本地存储，不通过上传您的设备数据获取。我们遵循隐私优先原则，计算和数据主要在您的设备上完成：您的设计内容和"我的数据库"默认仅存储在您的设备上；除下文另有说明外，我们不收集个人身份信息用于广告或第三方共享。

2. 信息收集与使用方式

2.1 基本原则
本应用不会将您的设计方案、变压器规格参数或"我的数据库"内容上传到开发者服务器；我们无法远程读取您设备中的此类数据。

2.2 设备上处理的信息
您输入或生成的数据包括但不限于：

  • 电气规格与设计约束（输入电压、多路输出、开关频率、工作模式、占空比及磁感应强度 / 电流密度限值等）
  • 磁芯选型、匝数比、线径、气隙、损耗与温升迭代及汇总结果
  • 本地保存的设计项目与界面偏好设置
  • "我的数据库"中的自定义铁氧体材料、磁芯和骨架

PDF 报告和 JSON 设计文件由您在设备上本地生成；若您通过系统分享、邮件或其他应用分享它们，则由您选择的收件方根据其条款处理。

上述信息仅用于在您设备上呈现计算结果和导出文件，不上传到开发者服务器。

2.3 分析与诊断（匿名）
我们可能通过 Microsoft 提供的标准机制（如 Microsoft Store 分析与匿名崩溃诊断）了解设备型号、系统版本和聚合使用信息，不包含您的设计详情。您可在 Windows 的"设置 → 隐私和安全性 → 诊断和反馈"中管理诊断数据共享，以限制此类报告。

3. 数据存储

设计数据主要存储在应用的设备本地数据目录中。卸载应用或清除其数据将根据系统行为删除本地内容。本应用不使用 iCloud 或其他云备份服务存储您的设计数据；若 Windows 将应用本地数据纳入您自行配置的系统级备份（例如文件历史记录），其处理受相关 Microsoft 服务自身条款约束，我们无法访问此类备份内容。

本应用不在本地保存试用开始日期，也不根据本地时间戳授予付费功能访问权限。年度订阅产品所含的 Microsoft Store 7 天全功能免费试用、试用资格、购买记录与自动续订由 Microsoft（Microsoft Store / Partner Center）处理；应用仅在需要时通过官方 Windows.Services.Store 接口读取有效的订阅或试用授权状态，并在设备本地缓存订阅状态与到期时间，用于界面显示和离线期间的基础状态保持。

4. 数据共享

我们不出售设计数据。根据应用分发、支付和系统服务的需要，Microsoft（Microsoft Store、Partner Center、订阅及购买/授权记录）以及您主动选择的网络通信接收方（如应用内打开的隐私政策或技术支持页面的托管提供商）根据各自条款处理最小必要信息。

5. 第三方与应用网页

若您在浏览器中打开应用提供的说明、隐私政策或技术支持页面，静态内容通过 HTTPS 加载，不包含个人跟踪的嵌入式脚本。GitHub Issues 等外部链接由您自行选择通过浏览器访问。

6. 儿童隐私

本应用不面向 13 岁以下儿童设计；我们不故意从儿童处收集个人信息。

7. 您的控制

您可在应用内管理设计方案和"我的数据库"；卸载应用将删除设备上的数据。年度订阅产品所含的 Microsoft Store 7 天免费试用、购买记录及自动续订由 Microsoft（Microsoft Store）根据其条款处理；相关账户和订阅设置由您在 Windows 设置（设置 → 应用 → 订阅）或 Microsoft Store 应用的"订阅"页面中自行管理。

8. 政策变更

我们可能更新本政策并更新此页面上的"最后更新"日期；重大变更将通过 Microsoft Store 发布说明或适当的应用内通知进行沟通。继续使用即表示接受更新后的政策。

10. Windows 平台说明

本应用通过 Microsoft Store 以打包的 Windows 桌面应用形式分发（MSIX），界面基于 WebView2 本地渲染。无论您使用哪种 Windows 设备，数据处理原则相同：变压器设计和计算在您的当前设备上进行，本产品不向开发者传输您的设计文件内容。

应用使用不需要位置、摄像头、麦克风或其他不必要的权限；磁芯迭代与损耗计算可完全离线完成；打开 Microsoft Store 订阅页面、验证购买/试用状态或浏览网页帮助需要网络连接。

首次启动时，Windows 可能会执行标准的应用完整性检查（如 Microsoft Defender SmartScreen），这是平台官方安全机制的一部分，可能需要网络连接；之后应用可离线运行。设计项目存储在应用的本地数据目录中，不与其他应用共享。

年度订阅产品所含的 Microsoft Store 7 天免费试用和年度订阅由 Microsoft 完成（包括 Microsoft Store 订阅与试用期规则，如应用内和 Microsoft Store 所示），我们不使用订阅进行第三方广告分析。
