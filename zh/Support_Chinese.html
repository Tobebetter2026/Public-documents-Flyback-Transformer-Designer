反激式变压器设计工具

最后更新：2026-05-21

反激式变压器设计工具是面向电源工程师的离线反激式变压器设计应用：从电气规格与约束出发，自动完成磁芯选型、匝数与线规、损耗与温升估算，并生成可存档的 PDF / JSON 报告。全部计算在您的设备本地完成，设计数据不上传开发者服务器。

适用于通过 App Store 安装的 iPhone、iPad、Mac（Apple 芯片 Mac 运行 iOS 兼容版本，以商店展示为准）。提供 14 天全功能免费试用；试用结束后可通过 年度订阅 继续使用。

产品优势

  • 专为反激式设计：支持 DCM / BCM / QR / CCM，最多 3 路次级输出，覆盖常见反激拓扑与多输出电源。
  • 联合迭代选型：磁芯 × 匝数 × 线径（含利兹线）一次扫描，多方案对比，减少手工反复试算。
  • 内置数据库：建立磁芯、骨架与材料数据（E / ETD / PQ / RM / EFD 等），可按厂家筛选
  • 气隙与电感对齐：由 Lm、Np 解析反算气隙，含边缘磁通修正；Lm、B_peak、温升一并校验。
  • 可扩展数据库：「我的数据库」在本机维护自定义材料、磁芯、骨架，与内置库合并参与选型。
  • 隐私与离线：核心设计可离线使用；无第三方广告；与「电感设计专家」为独立应用，账户与数据不互通。

主要功能

  • 整流桥直流输入、多路输出规格与交叉调节提示。
  • AP 法磁芯预选、iGSE / Steinmetz 铁损、Dowell 铜损谐波修正。
  • 窗口分配、绝缘线规与热等级约束。
  • 界面：简体中文 / English。

使用流程（三步）

  1. 规格与约束 — 输入电压、多路输出、开关频率、工作模式及 Bmax、Jmax、Ku 等约束。
  2. 磁芯与绕组 — 查看迭代候选方案，按损耗、温升、磁密与窗口利用率选定设计。
  3. 汇总与报告 — 核对参数表与警告说明，导出 PDF 或 JSON 文件。
